# WU-012 — original-formula random XNF structural audit (negative result)

**Status:** completed and falsified as a useful general feature signal on this
corpus. This is input-feature research, **not a new SAT solver**, and makes no
runtime-speedup or theoretical-complexity claim.

## Research question and prior foundation

WU-011 identified 313 instances jointly unsolved by independently evaluated
improved CryptoMiniSat and native-XNF Xorcle. 204 are random 2-XNF formulae:
136 in `2xnf-rand`, 68 in `2xnf-rand_sat`. We ask a narrower question:

> Are **cheap, original-input** parity cancellation statistics predictive of
> *both solvers timing out*, after controlling for variable count and the
> planted-solution/random benchmark family?

For each XNF disjunction of two affine linerals, consider the two variable
support vectors `a,b` over GF(2), and their Hamming distance
`d = popcount(a XOR b)`. We hypothesized that shorter cancellations might
make some instances more tractable. Before evaluating held-out labels, we
fixed these three features: `min(d/n)`, `mean(d/n)`, and fraction of clauses
with `d <= floor(n/3)`. This is a *heuristic hypothesis*, not a novel
mathematical construction and does not use any assignment enumeration.

Related established theory/algorithms: Beame and Sun, *Extending CDCL to
Disjunctions of Parity Equations*, SAT 2026,
<https://doi.org/10.4230/LIPIcs.SAT.2026.5>; original public data and
solver comparisons by Mate Soos, <https://msoos.github.io/xnf-tests/>.

## Design fixed before outcome inspection

- Input labels: `jointly_unsolved = !cms_improved_solved && !xorcle_solved`
  at the original benchmark's 180-second per-run deadline.
- Split: `FNV-1a("family/instance") % 5 == 0` for held-out cases, giving
  624 training and 176 test instances. Formulas, labels and all three
  hypothesized features are pre-specified before examining test metrics.
- Baseline logistic model: intercept + standardized `n` + binary family.
- Augmented logistic model: baseline + three parity cancellation features.
  Standardization fitted on training only. Same fixed 2,200 gradient steps,
  step 0.40, ridge penalty 0.02 for all non-intercept coefficients in both
  models; no fit/tuning on held-out instances.
- Primary evaluation: held-out Brier score, which rewards calibrated failure
  probabilities. Secondary: log loss and family-specific Brier score.
- Negative control: 999 seeded permutations of all three held-out parity
  features together, independently within each `(family,n)` stratum,
  scored under the **unchanged trained augmented model**. Reported `p` is
  the one-sided conditional shuffle tail fraction with a +1 correction;
  it does not establish cross-corpus significance.

## Recorded full-original-corpus results

| Split/model | N | Jointly unsolved | Brier | Log loss |
| --- | ---: | ---: | ---: | ---: |
| Training, baseline | 624 | 157 | 0.058486 | 0.209962 |
| Training, + parity | 624 | 157 | 0.058321 | 0.208468 |
| Held-out, baseline | 176 | 47 | 0.055961 | 0.203589 |
| Held-out, + parity | 176 | 47 | 0.055613 | 0.201882 |

Observed held-out Brier gain **0.000347** (baseline minus augmented).
Within-`(family,n)` negative-control permutation: **699/999** shuffled cases
had gain at least as large as observed, one-sided `p = 0.7000`.

Held-out family-specific baseline/augmented Brier scores:

- `2xnf-rand` (80, 23 jointly unsolved): **0.051838 / 0.050429**.
- `2xnf-rand_sat` (96, 24 jointly unsolved): **0.059396 / 0.059933**.

The feature set therefore **fails our evidence gate**: the tiny overall
improvement does not distinguish a genuine support-geometry signal from a
noisy size/family proxy. We should not put this feature gate into a SAT solver.

## Unexpected useful characterization: sharp size/censoring cliff

There are 20 instances of each family at **each** variable count 21–40,
with 3n XNF clauses. At `n=21..33`, neither solver timed out on any of the
260 instances in *each* family. For n=34..40:

| n | Random jointly unsolved / 20 | Planted jointly unsolved / 20 |
| ---: | ---: | ---: |
| 34 | 16 | 2 |
| 35 | 20 | 2 |
| 36 | 20 | 4 |
| 37 | 20 | 12 |
| 38 | 20 | 15 |
| 39 | 20 | 16 |
| 40 | 20 | 17 |

Unplanted random benchmark problems transition in this dataset from zero
**joint timeout** events through n=33 to 16/20 at n=34 and all at n>=35.
Planted problems transition later and less sharply, for example 2/20 at
n=34 and 17/20 at n=40. These are **published timeout events with a fixed
180-second censoring limit**, not a mathematical phase transition or
complexity lower bound. Source-generated formula difficulty and the
presence/absence of a planted satisfying assignment are confounded, so
the cause of the gap remains unidentified.

## Reproduction

From repository root, after separately downloading and SHA-256-verifying the
original public SQLite and two ZIP files, run the bridge and Rust experiment:

```sh
python3 scripts/wu012_export_random_xnf.py \
  /path/to/xnf-tests/data.sqlite \
  /path/to/2xnf_sat_solving/benchmark/rand/rand.zip \
  /path/to/2xnf_sat_solving/benchmark/rand/rand_sat.zip \
  | cargo run --release --manifest-path rust/witnora-ve/Cargo.toml --bin wu012_xnf_structure

cargo test --release --manifest-path rust/witnora-ve/Cargo.toml --bin wu012_xnf_structure
cargo test --release --manifest-path rust/witnora-ve/Cargo.toml --all-targets
```

The exporter writes only to stdout; it does not modify source data or copy
copyrighted/public source archives into Witnora. The Rust program validates
the full source schema and emits all per-size strata and fit metrics.

## Falsification and next research gate

1. **Rejected:** add min/mean/short XOR-support cancellation fractions to
   predict joint failure. No compelling incremental out-of-sample signal.
2. **Open:** explain the solver cutoff at n≈34 in original unplanted random
   2-XNF without mistaking a deadline artifact for a complexity threshold.
3. **Next independent gate:** vary *both* n and deadline, measure at least
   one additional independent solver on the actual XNF formulae, and compare
   native parity-constraint proof-search behavior to ordinary CNF lowering.
   Use held-out instances from a **new generator seed**, not the dataset on
   which this size cliff was found. Measure verified SAT/UNSAT and wall time.

No new solver run, proof complexity theorem, or novel SAT transformation is
claimed in WU-012.
