# W031 — frozen 16-seed clause-order robustness experiment

**Frozen before timing.** This study tests *only* the W026 synthetic parity
generator with fixed 8,192 noise clauses, plus four W027 planted-SAT decoys.
It does not test external SAT problem distributions or P-versus-NP complexity.

## Design

- Exactly 16 independently seeded noise realizations at 8,192 noise clauses;
- For each seed, the same matched SAT and UNSAT core under three clause orders:
  (1) contradictory core first, (2) core last, (3) deterministic Fisher-Yates
  full-CNF permutation using label-blind seed `0x03103100 ^ (r*0x9e3779b9)`;
- Exactly 96 matched source CNFs, plus 4 deterministic near-XOR planted-SAT
  negative controls reused from W027: **100 distinct source files**;
- All original CNF byte SHA-256, variable counts, clause counts, noise seeds,
  noise fingerprints and core position spans are frozen in
  `research/results/w031_order_case_manifest.json`, generated by
  `scripts/w031_order_cases.py`. SAT/UNSAT partners share precisely the same
  source clause-order permutation.

## Three frozen solver arms

1. Kissat `rel-4.0.4` at commit
   `8af8e56f174b778aef3aa45af9f739b2a5f492c2`, unchanged-CNF input.
2. Original W027 Rust all-clauses-first parity precheck plus unchanged-CNF
   Kissat on `NO_CERTIFICATE`.
3. New W030 Rust **incremental prefix** parity precheck plus unchanged-CNF
   Kissat on `NO_CERTIFICATE`.

Three repeats per case per arm, arm order rotated by source case index and
repeat: **900 timed end-to-end solver invocations**. Every attempt has a
6-second complete pipeline cap and 2GiB address-space cap, matching the W030
pilot; no retries or case selection by performance. This is a controlled
synthetic study, not a substitute for W027's 30-second official external suite.

Each timed SAT witness is checked against original source clauses and each
timed Rust UNSAT certificate is independently audited against source quartet
indices. An additional *untimed* diagnostic Rust run per case records the
fraction of source clauses read; it is never included in the three-arm timing
comparisons. Any mismatched result, bad proof, wrong source digest, or missing
timing row fails the benchmark.

## Prespecified statistics (before running)

The primary estimand is `mean[ median(time_W027_UNSAT) −
median(time_W030_UNSAT) ]` over the 16 matched noise seeds in the
**shuffled** clause-order stratum. The primary H1 acceptance condition is a
positive *lower* endpoint of a 95% paired bootstrap interval (5,000 seed-pair
resamples, fixed analysis seed). Otherwise the claim of a robust W030 speedup
over W027 under shuffled order is **not supported**.

Secondary, equally important results for **each** order:

- Mean SAT cost `s = W030+Kissat − Kissat`, mean UNSAT saving
  `g = Kissat − W030+Kissat`;
- Equal SAT/UNSAT balanced overhead `(s−g)/2` and paired-bootstrap interval;
- An illustrative UNSAT prevalence threshold `p > s/(s+g)` only if both
  `s` and `g` are positive;
- Mean/min/max fraction of input clauses consumed before proof, independent
  of timed invocations; and explicit near-XOR SAT false-positive audit.

Bootstrapping is over 16 independent noise seeds; three timing repeats are
collapsed to medians **before** bootstrapping. Intervals are conditional on
this constructed family and do not estimate general SAT performance. No
post hoc case filtering, no retrospective seed changes, and no extrapolation
to arbitrary NP-complete instances are allowed.

## Falsification interpretation

The prefix algorithm can prove UNSAT on a partial source only when enough
signed clauses have arrived for a GF(2) contradiction. Reordering clauses
does not change the truth value but can delay the proof until almost all
constraints have been read. If the shuffled-order primary test fails, or
balanced-case latency remains worse than Kissat, report this limitation as a
negative result. Neither outcome entails P = NP or P ≠ NP.
