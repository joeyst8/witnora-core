# Operator Genesis Program

The Operator Genesis program asks whether obstruction fingerprints can guide
the invention of new collapse operators.

The research loop is:

1. Run bounded grammars.
2. Record non-collapse or limited-collapse rows.
3. Extract deterministic structural fingerprints.
4. Generate candidate operator schemas.
5. State certificate obligations.
6. Queue theorem candidates.
7. Promote only when checker and test obligations are explicit.

## Relation to Verifier-to-Witness Collapse

The long-term target is verifier-to-witness structure: identifying conditions
under which a polynomial-time verifier instance admits a deterministic,
certificate-checkable route to a witness or proof.

v2.4 does not claim progress on P vs NP. It builds a disciplined generator for
future operator hypotheses.

## Candidate Status

Generated candidates are not implemented operators. They are research objects
with:

- trigger signatures
- intended transformations
- preservation obligations
- certificate obligations
- safety risks
- forbidden interpretations

No candidate becomes trusted until implementation, independent checking,
targeted tests, artifact generation, and claim-boundary review are complete.

## First Novel-Operator Breakthrough

A true breakthrough requires more than a high ranking. It requires a generated
operator to become an implemented, independently checkable collapse path on a
target family without fake solver, DRAT, theorem, or complexity claims.

## v2.5 Prototype Promotion

The first promotion is `ORBIT_COUNTING_COLLAPSE` to
`G4_ORBIT_CAPACITY_COUNTING_PROTOTYPE`.

The promoted operator is intentionally bounded. It handles exact generated
assignment/resource CNFs with native Hall/capacity-deficit certificates. It does
not become a theorem, a DRAT route, or a full matching/allocation solver.

The promotion criteria were:

- exact trigger family for local capacity deficits;
- native certificate schema;
- independent checker that expands orbit evidence;
- balanced controls that do not emit contradictions;
- duplicate complete-matching controls that are not counted as novel G4 deltas.
